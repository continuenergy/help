# Continu Help

Short animated how-tos for Continu's PowerPoint and Word templates.

Live site: https://continuenergy.github.io/help/

- `index.html` – the help page. Topics are listed in the `TOPICS` list near the bottom of the file.
- `assets/GIFs/` – each topic's animation (`.gif`) and its preview image (`.jpg`).
- `assets/Icons/` – the PowerPoint and Word app icons.

Set up and maintained by Ideer Creative.
